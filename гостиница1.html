Перетащите сюда Excel, CSV, PDF или фото прайс-листа — либо нажмите кнопку выше.
Распознаются категории номеров, количество и стоимость (будни / выходные). Таблица на этой вкладке заполнится из файла.
ℹ️ После поиска выберите гостиницу — цены подтянутся сами. Либо загрузите перечень номеров и цен файлом.
📌 Как редактировать: Нажмите «✏️ Редактировать» – ячейки станут доступны для изменения. После правок нажмите «💾 Сохранить». Кнопка «🔄 Сбросить» вернёт автоматические цены.
📄 Загрузка файла: Excel / CSV / PDF / фото прайса распознаются и выводятся в таблицу категорий и цен.
➕ Добавление категории: заполните поля ниже и нажмите «Добавить».
📊 Будни / Выходные: для каждого месяца отдельные цены (без завтрака). В шапке и строке «Количество дней» — число дней месяца (будни / выходные). ADR в месяц (по месяцу) = цена будней × дни будней + цена выходных × дни выходных. ADR за год = сумма ADR по месяцам / число дней с ценами. Итоговый ADR в месяц = ADR за год × 31. ADR без НДС, без завтрака, с кор-кой от стойки = ADR за год × 0,8 / 1,22. Средние будни/выходные по формуле 5/7 сохранены.
🍳 Завтрак: стоимость завтрака можно изменить — средние пересчитаются.

📊 Метод дисконтированных денежных потоков (МДДП)
📌 Примечание: Расчёт совпадает с листом Excel «Расчет_МДДП_детализация_расходы». Ячейки с тёмным фоном можно редактировать. Строка «Рост средних цен за номер в год» подставляется из вкладки INPUTS (строка «Темп роста ADR гостиниц, г/г», годы 2027–2032). Эти ячейки можно править вручную — после правки они больше не перезаписываются из INPUTS. Базовая плата — % от выручки, incentive — % от GOP, royalty — % от дохода номеров. НДС возмещаемый добавляется к NOI в годы 1–5. Реверсия дисконтируется коэффициентом конца 5-го года.
